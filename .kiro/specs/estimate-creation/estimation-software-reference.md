# 参照モデル: 建設業向け積算ソフトの行操作・階層構造

本書は、見積書作成機能の行操作・ネスト構造を再設計するにあたり検討した一般的な建設業向け積算ソフトの仕様の記録である。要件定義に必要な範囲をここに保存する。

> 注意: 本書は**参照モデルの記録であって、ArchiTrack の要件ではない**。どこまで採用するかは requirements.md で判断する。参照資料に記載が無い事項は「記載なし」と明記している。

---

## 1. 階層（ネスト）モデル

- 見積書類は「表書 / 明細 / 工事コメント」の3タブ構成。**階層を持つのは明細のみ**。
- 明細はツリー状の入れ子を持つ。最上位を「トップ階層」、末端を「最下層」と呼ぶ。中間ノードは「内訳（下階層を含む明細）」、末端は「明細」。
- **1行がそのまま子階層の親ノードになる（行 = ノード）**。子を持つ行の名称が、その子階層の「明細タイトル」になる。
- 画面の「区」列に階層状態を記号表示する（入力不可の表示専用列）。
  - `↓` = 最下層のデータ（子なし）
  - `→` = 下に階層を持つデータ（子あり）
  - 行属性が設定されていればその省略形（`小` `中` `大1` 等）
- 名称マスタも書類と同じ階層構造を持つ。

### 最大階層数
**明示的な記載なし。** 間接的な手がかりのみ:
- 書式の[共通設定]で階層別設定は「階層1〜階層6」まで
- 階層ごとに割り当てるページ書式は「明細1〜9」

### 親子の金額集計ルール
- 末端（最下層）の `数量 × 単価 = 金額` がボトム値。見積・実行それぞれに数量/単価/金額を持つ。
- 子階層の合計が親行の金額へ積み上がる。書式に「階層合計金額 / 階層実行合計 / 階層粗利合計 / 階層粗利率」があり各階層の明細合計から自動計算される。
- **「積上合計（積）」行属性が積上げの打ち切り境界**。上階層へ積上げる金額を上書きし、金額調整はこの積上額のみを対象とする（配下の各明細行には反映されない）。主に隠れ階層で使用。
- 金額調整（率・額指定）は**最下層の単価を調整**する。
- 金額調整/金額作成/粗利率算出/消去チェックの各コマンドは、**カーソル行に階層下が無い場合は無効**＝階層ノードに対して再帰的に働く。
- 派生値（入力不可）: 単価粗利 = 見積単価 − 実行単価、単価率 = 単価粗利 ÷ 見積単価 × 100、金額粗利 = 見積金額 − 実行金額、粗利率 = 金額粗利 ÷ 見積金額 × 100。

### 展開/折りたたみ
- 折りたたみUIは**ツリーパネルの「ツリー表示」モードのみ**。`＋`/`−` ボタンで全て開く/全て閉じる。個別ノードの開閉キー割当は記載なし。
- **明細グリッド本体は折りたたみではなく「現在階層だけを表示する」ドリルダウン型**。

### 階層移動（ドリルダウン/アップ）

| 操作 | トリガー | 挙動 |
|---|---|---|
| 階層上 | **F2** / ツールバー / 階層タブクリック | カーソルを上の階層へ（親へ戻る） |
| 階層下 | **F3** / ツールバー | カーソルを下の階層へ（子へドリルダウン） |
| 前の階層 | **Ctrl+B** | 一つ前の階層の先頭行へ |
| 次の階層 | **Ctrl+N** | 次の階層の先頭行へ |
| 先頭階層 | メニュー | 明細内で先頭階層の先頭行へ |
| 最終階層 | メニュー | 明細内で最終階層の先頭行へ |
| 階層内の先頭行 | **Ctrl+↑** | 表示中の階層内の先頭行へ |
| 階層内の最終行 | **Ctrl+↓** | 表示中の階層内の最終行へ |
| ツリーからジャンプ | ツリーパネルの項目をダブルクリック | 該当明細へカーソル移動 |
| 検索でジャンプ | **Ctrl+F** | 名称/規格を検索。**検索は階層をこえて行われる** |

- 「階層タブ」というUI要素があり、クリックで上階層へ戻れる（パンくず相当と推測されるが詳細の記載なし）。
- ウィンドウ二重化により、同一書類内で違う階層を同時に表示・編集でき、変更は相互反映される。

## 2. 行属性（19種）

設定は **F9**（プルダウン）または[機能]-[行属性]。設定すると名称欄に行属性文字が自動流し込みされ（既定は `【○○】`）、「区」欄に省略形が表示される。

**解除手段は「一行削除」のみ**。文字を消しても通常行には戻らない ＝ **行に不変の type フラグを持つ**。

| 行属性 | 区 | 振る舞い |
|---|---|---|
| 値引 | 値 | 金額欄に直接入力。**マイナスが自動付加**、プラス入力不可。単価は印刷されない |
| 雑費 | 雑 | 金額欄に直接入力。マイナスも可。単価は印刷されない |
| 小計 | 小 | 1行目 or 直前の 小計/中計/大計/大大計/大大大計 から当該行までの合計 |
| 中計 | 中 | 1行目 or 直前の 中計/大計/大大計/大大大計 からの合計 |
| 大計 | 大1 | 1行目 or 直前の 大計/大大計/大大大計 からの合計 |
| 大大計 | 大2 | 1行目 or 直前の 大大計/大大大計 からの合計 |
| 大大大計 | 大3 | 1行目 or 直前の 大大大計 からの合計 |
| 備考 | 備 | 明細内メモ。「行属性の突き抜け表示」で項目枠を突き抜けて表示可 |
| 改め値引 | 改 | 金額欄に直接入力。プラス/マイナス両方可。**印刷時は空白** |
| 経費 | 経 | 歩掛欄の掛け率 × 「経費フラグON明細の集計額」で自動算出 |
| 消耗品1 / 消耗品2 | 消1/消2 | 同上（それぞれ独立フラグ） |
| 運搬費 | 運 | 同上 |
| 労務費 | 労 | 歩掛率×数量で工数、工数和×労務単価＝労務費 |
| 消費税 | 税 | **トップ階層に限り**使用可。上の行までの合計×税率。書式の税区分を「明細内」にする必要あり |
| 小計（×） | — | 金額 = 小計 × 数量 |
| 小計（÷） | — | 金額 = 小計 ÷ 数量 |
| 加算 | 算 | 直前の合計属性の指定％を自動計算し、**直前の合計属性に加算**。％は歩掛欄 |
| 積上合計 | 積 | 上階層へ積上げる金額を上書き。金額調整はこの積上額のみ対象 |
| 法定福利費 | 法 | **トップ階層のみ**。簡易法定福利費 算出画面を表示 |
| 改ページ | ＊ | 強制改ページ |

### 属性以外の行フラグ
経費 / 消耗品1 / 消耗品2 / 運搬費 / 法定福利費 の5種チェック欄（歩掛計算の集計対象マーカー）。分類コード・業者コードも行に持つが、**下階層のあるデータでは最下層の明細にのみ有効**。

### 再計算のタイミング
- 環境設定の「**行属性は自動計算**」チェックで自動/手動を切替。
- OFF なら入力のたびに再計算せず、[行属性の再計算]（全体）または **Shift+F7**（カーソル位置の個別再計算）で明示的にバッチ再計算する。

## 3. 行操作の一覧

| 操作 | トリガー | 挙動 | 対象範囲 |
|---|---|---|---|
| 一行挿入 | **F6** | カーソル位置に空白行1行挿入、以降が下へずれる | 単一行 |
| 一行削除 | **Shift+F6** | カーソル行を削除、以降が上へ詰まる | 単一行 |
| 削除 | **Delete** | 範囲指定行を削除。**カットバッファに入らない＝貼り付け不可** | 複数行 |
| 切り取り | **Shift+Del** | 範囲指定行を削除しカットバッファへ登録（既存内容を破棄して置換） | 複数行 |
| コピー | **Ctrl+Ins** | 範囲指定行をカットバッファへ登録（元行は不変、既存内容を破棄） | 複数行 |
| 追加切り取り | **Shift+Ctrl+Del** / 行選択時 **F6** | 削除しカットバッファに**追加**登録 | 複数行・複数階層 |
| 追加コピー | **Shift+Ctrl+Ins** / 行選択時 **F7** | カットバッファに**追加**登録。「違う階層や連続していない複数の行を拾い集め、一個所に貼り付ける」用途 | 複数行・複数階層 |
| 行貼り付け | **Shift+Ins** | カットバッファの内容をカーソル位置へ。**行貼り付け＝行挿入**（以降が後ろへずれる） | 複数行 |
| 行選択 | **Shift+↑↓**, **Shift+PageUp/Down**, マウスドラッグ | 行単位の範囲選択 | — |
| 行選択解除 | **Esc** | 範囲指定解除 | — |
| 上階層へ移動 | **Ctrl+↑** / 行選択時 **F8** | 範囲指定行を一つ上の階層へ | 複数行 |
| 下階層へ移動 | **Ctrl+↓** / 行選択時 **F9** | 範囲指定行を一つ下の階層へ。**便宜上、最初の行の名称が上階層（親）の項目名称として使用される** | 複数行 |
| 1行上の項目を複写 | **F7** | **カーソルのある項目（列）だけ**、1行上の同じ項目値を複写入力 | 単一セル |
| 行属性選択 | **F9** | 行属性を設定 | 単一行 |
| テンプレート保存 | 行選択後 **F3** | 範囲指定行を**階層下を含む全明細**でテンプレート化 | 複数行＋配下階層 |
| テンプレート挿入 | メニュー | カーソル位置に**階層下も含めて**挿入 | 階層丸ごと |
| マスタへ登録 | **F5** / **Shift+F5** / 行選択時 **F2** | 明細行/範囲を名称マスタへ登録 | 単一行/範囲 |
| 明細挿入 | [ファイル]-[明細挿入] | 他の書類の明細データ全体をカーソル行に挿入 | 書類丸ごと |
| 元に戻す | **Ctrl+Z** | **10回まで**。誤削除した明細行の復元に使える | — |
| 金額調整を元に戻す | メニュー | 1手順戻す。**実行直後のみ有効** | — |
| 消去／チェック項目 | メニュー | 数量/単価/歩掛の一括消去、5種フラグの一括ON/OFF | **カーソル行の階層下から一括**（再帰） |
| 見積→実行 / 実行→見積 の複写 | メニュー | 数量・単価・歩掛率を反対側へ複写し再計算 | カーソル行 or 全体 |
| 見積・実行の交換 | メニュー | 見積金額と実行金額を入れ替え | 書類全体 |

> **明細行のソート／並べ替え機能に関する記載は見つからなかった。**（「並替項目」「並替方向」は書類エクスプローラのファイル一覧用）
> **ドラッグ&ドロップによる行移動/階層移動の記述も無い**（範囲選択のドラッグのみ）。

## 5. クリップボード / テキスト入出力

### 二重のバッファ体系
- **カットバッファ**: アプリ内独自の行バッファ。行の切り取り/複写の内容を保持し、行貼り付けで明細へ転送する。**追加切り取り/追加コピーで蓄積可能**＝複数階層・非連続行を寄せ集めて1箇所に貼れる。**異なるウィンドウ間でも複写／貼り付け可能**。
- **OSクリップボード**: 文字列（Ctrl+C/V）と、階層単位のタブ区切りデータ入出力に使用。

### 現在階層 ⇄ クリップボード
- [入出力]-[現在階層からクリップボードへ出力] / [現在階層へクリップボードから入力]
- 入出力される項目と項目順は環境設定で決定。**このコマンド経由ではヘッダーは出力されない**（入力時も「無」扱い）。
- アプリ内でのデータ移動・複写にも使える＝階層単位のコピー&ペースト経路。

### 現在階層のテキスト入出力
- 形式: タブ区切 / カンマ区切 / クリップボード（タブ区切） / Excel（出力のみ）
- 入出力対象項目リストと除外項目リストを移動させて**項目の取捨と順序**を定義。
- 特殊項目「**ブランク**」: 出力時は空カラムを出力、入力時はその位置を無視 ＝ **外部CSVの列ズレ吸収機構**。
- 取り込み前に内容をプレビュー可能。

### 書類全体のテキスト出力
- 隠れ階層の出力: 有/無
- 出力範囲: 「全て（トップ階層〜最下層）」/「トップ（トップ階層のみ）」/「最下層（最下層の明細のみ）」

## 6. UIパネル構成

### フロートパネル（4種、ドッキング/ウィンドウ化可能）
| パネル | 役割 |
|---|---|
| **項目パネル** | カーソル位置の項目に応じて選択メニュー/名称マスタ/宛名マスタ/書式一覧を表示。**数値項目では電卓**。ダブルクリック or Enter で流し込み |
| **ツリーパネル** | 書類の階層構造をツリー表示。**3表示モード**（分類表示=中間階層のみ / 名称表示=最下層まで全フラット / ツリー表示=エクスプローラ風折りたたみ）。ダブルクリックでジャンプ。階層ごとのページ書式割当。**同期は明示的な「再読込」**（カーソル移動では非同期、編集時は自動再読込） |
| **テンプレートパネル** | テンプレート/既存書類をツリー表示し、選択部分を明細へ流し込む。「流し込み時に階層下も含める」トグル |
| **クリップパネル** | **入力履歴**を自動一時記憶（アプリ終了で全消去）。流し込み/読み込み/削除/全クリア |

### 固定パネル
- **詳細パネル**（上部）: 画面表示モード・書類名・現在行
- **見積ステータスパネル**（下部）: 見積合計・消費税額
- **実行ステータスパネル**（下部）: 実行金額・粗利合計

### 明細グリッドの表示モード（F8で巡回切替）
`見積1行(定義1/定義2)` / `見積2行` / `見積2行複合` / `実行1行(定義1/定義2)` / `実行2行` / `実行2行複合` / `標準2行` / `標準2行複合`
- 2行モード = 1レコードを2物理行で表示（備考欄が出る）。2行複合 = 分類/業者/経費等のチェック欄も出る。
- 1行モードは表示項目と桁数を自由定義可能。
- **カーソル移動順・IME制御は表示行数モードごとに独立設定**。

### 入力制御（Ctrl+A で巡回切替）
| モード | Enter | ← | ↑↓ |
|---|---|---|---|
| 標準 | 次の項目 | 前の項目 | 上下の行（2行モードでは2行ずつ） |
| シンプル | 次の項目 | 前の項目（↑も） | ↓も次の項目扱い |
| フリー | 次の項目 | 前の項目 | 上下の行（2行モードでも1行ずつ） |

項目ごとの入力順（0=スキップ）とIME制御（停止/オフ/オン/制御無/半角英数/全角英数/全角ひらがな/半角カタカナ/全角カタカナ）を設定可能。

## 7. 設計上の示唆（ローカル完結型の操作モデルという観点）

1. **「現在階層」を単位とした画面モデル**: 明細グリッドは常に1つの階層のフラットな行リストしか表示しない。取得・描画・保存の単位が階層であり、テキスト/クリップボード入出力もすべて「現在階層」単位。→ サーバー往復の自然な粒度が階層になる。

2. **アプリ内カットバッファをOSクリップボードと分離**: 行バッファはセッションスコープのクライアント状態。追加コピーで蓄積し、貼り付け確定時にまとめて反映できる。

3. **行属性が不変の行タイプ**: 解除操作を提供せず delete+insert で扱う。データモデルでは `rowType` を必須列にする設計。

4. **計算の自動/手動をユーザーが選べる**: 「行属性は自動計算」OFF なら明示トリガーでバッチ再計算。**重い集計を遅延・明示トリガーにできる設計が最初から入っている**。大規模明細でのレスポンス設計に応用可能。

5. **集計の打ち切り境界を持つツリー計算**: 金額調整は最下層の単価を触るのが一貫ルール。例外は「積上合計」属性で、そこから下は不変。

6. **ネスト化で親名称を自動生成**: 「下階層に移動」時、選択範囲の先頭行の名称が親の名称に昇格する。

7. **ツリーとグリッドの同期を意図的に緩くしている**: ツリーパネルはカーソル移動には追従せず、明示的な再読込か編集時のみ更新。コストの高い再構築を避ける設計。

8. **Undo は10回まで**（金額調整のUndoは実行直後1回のみ）。無限Undo前提ではないため有限リングバッファで足りる。

9. **入力履歴はセッションローカル**（アプリ終了で消去）。完全にクライアントメモリで済むオートコンプリート資源。

10. **テンプレート＝階層サブツリーの永続スニペット**。サブツリー単位の再利用がファーストクラス機能。

11. **書類間・ウィンドウ間の行移動が前提**。同一書類の複数ビュー間の状態共有を考慮した設計。

- 行数上限・明細件数上限
- 行属性の内部識別子・数値コード
