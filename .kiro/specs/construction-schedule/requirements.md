# Requirements Document

## Project Description (Input)
工程表作成機能を追加してください。この機能は建設業向けの工程表を作成する機能です。この機能は、工程表一覧画面と工程表詳細画面から構成されます。まず工程表を新規作成する場合、同一プロジェクトの数量表を任意で指定します。（指定しなくても可）。数量表を指定している場合は、当該数量表の項目一覧が数量表の順序で表示されます。それぞれの項目に対して、着工、日数をそれぞれ入力可能とします。入力を確定すると、工程表がリアルタイムでビジュアル化されて表示されます（リアルタイム表示処理はフロントエンド処理で完結させ、サーバーへの負荷は最低限とする）。工程表には、土日祝が色分けされて表示されます。また、数量項目とは関係なく、任意項目も追加、入力可能とします。また、ここで入力した項目は順番を変更可能で、順番は保存されます。工程表はExcelまたはPDF形式で、プロジェクト名、自社名を付けて出力可能とします。
