# Discovery Addendum: 画像一括エクスポートと全形状の白縁取り対応

- **作成日**: 2026-05-29
- **対象spec**: site-survey（既存spec更新 / Path A）
- **由来**: `/kiro-discovery` セッション（ユーザー要望: 現場調査画像の一括エクスポート機能追加、白縁取り対象形状の拡張）

本ドキュメントは、既存の `site-survey/requirements.md` に追加される新要件の根拠・スコープ・設計方針を、次フェーズ（`/kiro-spec-requirements`）に引き継ぐための記録である。

## 背景

現場調査機能は既に以下を備える（実装はフロントエンド `frontend/src/components/site-surveys/` 配下、API は backend 側の `imageService` / `annotationService`）。

- **個別画像エクスポート（Requirement 11）**: 1 画像単位で「画像形式（JPEG/PNG）」「解像度」「注釈含む/含まない」「元画像そのまま出力」を選択してダウンロード可能。
- **PDF 報告書エクスポート（Requirement 10）**: 報告書出力フラグが立った画像を PDF 化。
- **白縁取り表現（Requirement 24 / 25）**: 矢印（Req 24）とテキスト（Req 25）のみ白縁取り/白アウトラインを実装済み。本体色変更時も白固定、Undo/Redo 連動、保存属性化、後方互換ありの一式が完成している。

一方で次のギャップが運用上残っている。

1. **一括エクスポート機構が存在しない**: 1 現場調査に数十枚規模の画像がアップロードされるケースで、個別エクスポートを 1 枚ずつ繰り返す必要があり実運用が困難。
2. **白縁取りの対象が 2 形状に限定**: 寸法線・円・四角形・多角形・折れ線・フリーハンドは白縁取りなしのため、明背景／暗背景の混在写真で視認性が落ちる。

## 今回の対応範囲（In Scope）

### カテゴリX: 一括エクスポート（Requirement 11 の拡張）

| # | 項目 | 仕様 |
|---|---|---|
| X1 | 起動位置 | 現場調査詳細ページ。「全件一括エクスポート」と「選択画像エクスポート」の 2 起点をサポート |
| X2 | 選択 UI | 既存の画像一覧グリッド／チェックボックスを利用。0 件選択時は「全件」ボタンのみ活性 |
| X3 | エクスポート設定 | 個別画像エクスポート（Req 11）と同一の設定ダイアログを再利用: 画像形式（JPEG/PNG）、解像度、注釈含む/含まない、元画像そのまま出力。設定は対象画像群へ一括適用 |
| X4 | 出力形態 | ZIP で個別画像をまとめて 1 ファイルとしてダウンロード。ファイル名規則は既存個別エクスポートと整合 |
| X5 | 進捗表示 | 大量画像時はクライアントまたはサーバ側で進捗を可視化（具体方式は design フェーズで決定） |
| X6 | 既存エクスポート機構との整合 | Req 11 の単一画像レンダリングロジック（注釈描画・解像度変換・形式変換）を再利用し、二重実装を避ける |

### カテゴリY: 白縁取り対象の全形状拡張（Requirement 24 / 25 の拡張）

| # | 項目 | 仕様 |
|---|---|---|
| Y1 | 対象 6 形状 | 寸法線、円、四角形、多角形、折れ線、フリーハンド |
| Y2 | 仕様準拠 | Req 24（矢印）と同等: 白縁取り幅 = 本体線幅 × 1.5 以上、本体色を変えても白縁取りは白固定、移動/リサイズ/回転で同期変形、ユーザーが任意に有効/無効を切替可能、注釈データに属性永続化、保存済み注釈の白縁取り属性復元 |
| Y3 | サムネイル/PDF/エクスポート整合 | 編集画面と同一の白縁取り表現を、サムネイル・プレビュー・PDF 報告書・個別/一括エクスポートでも適用（Req 24 #8 と同方針） |
| Y4 | Undo/Redo | 白縁取り有効/無効切替を Undo/Redo 履歴に記録（Req 24 #10 と同方針） |
| Y5 | 後方互換 | 白縁取り属性を持たない既存注釈は、従来の白縁取りなし表現のまま表示（Req 24 #9 と同方針） |
| Y6 | 既定値 | 新規描画時の既定値は Requirement 26（既定スタイル一元管理）の方針に合わせて Req 24/25 と整合した既定有効状態とする |

## Non-Goals（今回の対象外）

- 一括エクスポートにおける PDF 単一ファイル出力（PDF 報告書は既存 Req 10 のスコープを維持）
- ブラウザの個別ダウンロード連続発火による疑似一括方式（UX ブロック懸念のため ZIP を採用）
- 白縁取り対象形状ごとの個別カスタマイズ（縁取り幅倍率など、形状別パラメータ化は今回はしない）
- 一括エクスポート進捗の永続化／中断レジューム

## 想定影響範囲（実装観点メモ）

実装は次のフェーズ（design / tasks）で確定するが、調査済みの参照点を共有する。

- 一括エクスポート: フロントは `frontend/src/components/site-surveys/` 配下のグリッド／エクスポートダイアログ、バックは `imageService` のエクスポートエンドポイントを再利用 + ZIP ストリーミングを新設する可能性。
- 白縁取り: `frontend/src/components/site-surveys/tools/` 配下の各形状ツールと `AnnotationEditor.tsx` 周辺の描画パイプライン。サムネイル／PDF／エクスポート時のレンダリングは backend / shared レンダラ両方の整合確認が必要。
