# プルリクエスト作成ガイドライン

## 1. デフォルトのマージ先ブランチ

特定のブランチが明示されていない場合、以下のルールで解釈する。

- **マージ元（head）**: 現在ローカルで作業中のブランチ
- **マージ先（base）**: `develop`ブランチ

ユーザーがマージ先ブランチを明示的に指定した場合は、その指定に従う。

## 2. PR作成前の確認事項

1. **現在のブランチ確認**: `git branch --show-current`で作業ブランチを確認する
2. **コミット漏れの確認**: 未コミットの変更がないかを確認する
3. **リモートへのプッシュ**: ローカルコミットがリモートにプッシュ済みか確認し、未プッシュであればプッシュする
4. **差分の確認**: `develop`ブランチとの差分（全コミット）を確認し、PRの内容を正確に把握する
