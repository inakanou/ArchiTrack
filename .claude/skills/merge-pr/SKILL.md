# プルリクエストマージガイドライン

## 1. デフォルトの解釈ルール

特定のPRやブランチが明示されていない場合、以下のルールで解釈する。

- **対象PR**: GitHub上でOpen状態のプルリクエスト
- **マージ先（base）**: `develop`ブランチ
- Open状態のPRが複数ある場合は、一覧を提示してユーザーに選択を確認する

ユーザーが特定のPR番号やブランチを明示的に指定した場合は、その指定に従う。

## 2. マージ後のブランチ削除

特別な指示がない限り、マージ完了後に不要となったブランチは削除する。

- マージ元のリモートブランチを削除する（`--delete-branch`オプションを使用）
- 対応するローカルブランチも削除する
- ユーザーが「ブランチを残して」等と明示した場合はブランチを保持する

## 3. マージ前の確認事項

1. **PR状態の確認**: `gh pr list`で対象PRのOpen状態を確認する
2. **CIステータスの確認**: PRのチェック（CI/CD）が通過しているか確認する
3. **マージ先の確認**: baseブランチが`develop`であることを確認する（異なる場合はユーザーに報告）
4. **コンフリクトの確認**: マージコンフリクトがないことを確認する
