# ローカル開発環境・ブラウザ動作確認ガイドライン

ブラウザでの動作確認にはローカル開発環境の起動が前提となる。
環境起動の手順は必ずREADME.mdから取得し、記憶や推測に頼らないこと。

## 1. 作業開始前の必須手順

ローカル開発環境の起動またはブラウザ動作確認を行う前に、以下を必ず実行する。

1. **README.mdの確認**: プロジェクトルートの`README.md`を読み、「クイックスタート」セクションから正しい起動コマンドを把握する
2. **起動状態の確認**: 既に環境が起動済みかを確認してから起動コマンドを実行する（二重起動を防止）
3. **アクセス先の確認**: README.mdに記載されたURL（ポート番号含む）を正確に使用する

## 2. 禁止事項

- README.mdを確認せずに起動コマンドを実行すること
- ポート番号やコマンド引数を記憶に基づいて推測すること
- README.mdに記載のない独自の起動方法を使用すること
