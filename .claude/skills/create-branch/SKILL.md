# ブランチ作成ガイドライン

## 1. 標準手順

特別な指示がない限り、以下の手順でブランチを作成する。

1. **リモートの最新取得**: `git fetch origin develop` でリモートの最新状態を取得する
2. **developブランチへ切り替え**: `git checkout develop` でdevelopブランチに切り替える
3. **ローカルを最新化**: `git pull origin develop` でローカルのdevelopを最新にする
4. **対応用ブランチの作成**: `git checkout -b <ブランチ名>` で最新のdevelopから新しいブランチを作成する

## 2. ブランチ名の命名規則

ユーザーがブランチ名を明示的に指定した場合は、その指定に従う。指定がない場合は、作業内容に応じて以下のプレフィックスを使用する。

- `fix/` : バグ修正
- `feat/` : 新機能追加
- `refactor/` : リファクタリング
- `chore/` : 設定変更・メンテナンス
- `docs/` : ドキュメント更新

## 3. ベースブランチの例外

ユーザーがdevelop以外のブランチをベースとして明示的に指定した場合は、その指定に従う。
